Materi pelajaran

Empat bidang yang saling terhubung. Kabel yang kamu crimping hari ini akan dilewati paket data yang kamu atur besok.

Jaringan

Satu permintaan halaman web melewati beberapa perangkat. Tekan tombol dan ikuti perjalanan paketnya.

  • Model OSI dan TCP/IP
  • Pengalamatan IPv4, subnetting, dan gateway
  • Switch, router, VLAN, dan routing statis
  • DNS, DHCP, NAT, dan troubleshooting dengan ping dan traceroute
Siap. Tekan "Kirim paket".

OSI 3D

Tujuh lapisan jaringan dalam bentuk tumpukan. Gerakkan kursor untuk memutar, klik lapisan untuk menggesernya keluar, atau kirim data dan lihat paketnya makin tebal tiap turun satu lapisan.

Pilih satu lapisan

PDU

Setiap lapisan menambahkan header miliknya sebelum data diteruskan ke bawah.


  

    
Server Linux

    
Server sungguhan hampir tidak punya antarmuka grafis. Semua dikerjakan lewat terminal, jadi kebiasaan mengetik perintah harus dilatih.

    
  • Instalasi Debian atau Ubuntu Server dan manajemen paket
  • User, grup, dan permission file
  • Web server Nginx, DNS server, dan file sharing Samba
  • Remote lewat SSH, firewall UFW, dan backup terjadwal

Kabel LAN

    
Urutan warna T568B dari kiri ke kanan. Salah satu saja tertukar, kabel tidak akan terhubung dengan benar.

    
    
      
  1. Kupas jaket kabel UTP sekitar 2,5 cm.
    2. 
      
  2. Urai dan luruskan keempat pasang kabel, lalu susun sesuai urutan T568B.
    3. 
      
  3. Potong rata ujungnya hingga tersisa kira-kira 1,2 cm.
    4. 
      
  4. Masukkan ke konektor RJ45 sampai semua ujung tembaga menyentuh bagian depan.
    5. 
      
  5. Crimping dengan tang, lalu uji memakai LAN tester.
